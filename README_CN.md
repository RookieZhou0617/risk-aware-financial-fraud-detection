> **核心问题：当企业自身风险模型已经较强时，异构关系还能提供什么额外预测信息？**

本研究先构建比较企业当前与历史状态的**多源偏差风险锚点模型（MDRA）**，再在冻结锚点之上学习选择性的图残差，形成 **MSAR-HGRN**。研究基于 FiGraph 年度数据，服务于财务造假风险排序与重点筛查；不将预测关联解释为因果归因，也不将其作为生产决策系统。

| 研究输入 | 评价设计 | 当前阶段 |
| :--- | :--- | :--- |
| 财务特征、MD&A 文本、自身历史、交叉拟合风险 | 2018–2021 滚动开发；2022 固定协议 OOT | 模型已冻结；五章论文初稿修订中 |

## 模型方法

**构建企业风险锚点 → 筛选关系补充证据 → 学习隐藏表示残差。**

1. **MDRA：先理解企业自身。** 在各来源内比较当前状态与同企业前两年的可用历史，融合当前信息、逐来源偏差与历史可用性。
2. **图残差：有选择地利用关系。** 按冻结锚点相似度保留前半数邻居，构造风险差异消息，经关系内均值聚合、可靠性门控及含 NULL 通道的跨关系注意力提取补充信息。
3. **冻结预测通路：保留模型起点。** 将零初始化的图残差加到锚点隐藏表示，再使用冻结的锚点分类器输出风险；第二阶段只训练图分支。

零初始化保证模型在**训练起点**与锚点一致；冻结参数不保证未来年份性能不下降。NULL 通道可以降低对关系证据的依赖，但不保证训练后的图残差为零。

## 实验证据

![各开发年度的关系增量与2022固定协议测试结果](assets/evidence-overview.svg)

### 2022 年固定协议 OOT

统一评价总体为 5,132 家公司，其中正例 123 家。下表使用**五个预设种子的算术均值**，不是五种子概率集成后的指标；AUC-PR 按 average precision 计算。

| 模型 | AUC-PR ↑ | AUC-ROC ↑ | LogLoss ↓ | F1 @ 0.5 ↑ | Recall @ 5% ↑ |
| :--- | ---: | ---: | ---: | ---: | ---: |
| MDRA · 企业内生风险锚点 | 0.489256 | 0.945054 | 0.056671 | **0.585282** | 0.809756 |
| MSAR-HGRN · 真实关系 | **0.507052** | **0.947675** | **0.054272** | 0.576771 | **0.814634** |

真实关系模型的平均 AUC-PR 较 MDRA 提高 **0.017797**，较匹配随机关系对照提高 **0.017414**（随机关系对照 AUC-PR 为 0.489639）；两项配对差值在 5/5 个种子下均为正。

> **保留证据边界。** 两组公司层配对 Bootstrap 的 95% 区间均跨零，2019 年开发折出现负迁移，最终 F1@0.5 较 MDRA 下降。因此结果支持关系增量的正向趋势，不构成统计显著、所有指标改善或时间稳健性已经成立的结论。

另报告六个可运行外部基线，包括 LightGBM（AUC-PR 0.407467）。基线与论文模型的输入家族不同，**不能把数值差异解释为同源架构优势**。2022 年 Source65 同源输入对照仍因精确输入产物缺失而阻塞。

## 运行示例

```bash
git clone https://github.com/RookieZhou0617/risk-aware-financial-fraud-detection.git
cd risk-aware-financial-fraud-detection
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python examples/synthetic_demo.py
python -m unittest discover -s tests -v
```

无需下载数据、无需 GPU，也不依赖专用图学习框架。示例用**完全合成的输入与标签**，演示零初始化图残差和一次仅图分支的优化。

这是精简的教学式实现，**不是论文的一键复现包**。示例中的锚点是随机初始化后冻结的，其损失值仅用于检查代码运行，不能作为实验结果。
